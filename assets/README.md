# NEU reference assets

These files are downloaded from the public NEU website for this educational
demo. They are not generated artwork. Branding and photographs belong to their
respective owners; this repository does not claim to be the official NEU site.

The demo reuses the original site's overlay navigation, full-width hero and
blue/red announcement strip. Admissions links come from `data/landing/news/`.
Images are served from local files, so viewing the UI does not request external
images, fonts or video. External article/navigation links open the actual sites.
